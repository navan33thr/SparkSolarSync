# SolarSync

A campus energy simulator for solar, geothermal cooling, battery storage and grid.

Built with TanStack Start, React, Tailwind CSS and Vite.

## Development

You need Node.js 20+ (or Bun).

```sh
npm install
npm run dev
```

## Build & deploy

```sh
npm run build
```

The build uses Nitro, which auto-detects Cloudflare, Vercel and Netlify. To target
something else, set `NITRO_PRESET`, for example for a plain Node server:

```sh
NITRO_PRESET=node-server npm run build
node .output/server/index.mjs
```

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run test` – run tests
- `npm run lint` – lint
